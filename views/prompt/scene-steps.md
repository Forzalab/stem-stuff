# View prompt: recipe scene-steps (library 0.2.0, profile stem)
Generated by tools/gen_views.py from views/registry.json. Do not edit.

Recipe: a step-through scene: objects in world units, one change per tap, an ask before the end (views/scene-contract.md). Length M. Stages: pre, wrong, post.

## Language (OpenUI Lang, profile stem)
- One statement per line: `name = Component(arg, ...)`, args in the order shown. The tree hangs off `root = View([...])`.
- Forward refs are fine. `$name = value` declares state.
- `q = Query("tool", {args}, {defaults})` asks an engine (server side). Never type a value an engine can compute.
- No Mutation, no Action, no navigation, no timers.
- The site draws every look. Never describe colours or sizes. State words are marks only: cur, done, front, rec, idle, tree, seen, skip, k1, k2, k3.
- Caps: `string≤N` = at most N characters, `[]≤N` = at most N items. Over a cap the statement is dropped.
- Nothing fits? Draw a `Doodle`. Never send a view with no visual.

## Bank refs
- `given.*`: item givens (given.m, given.v0). Stages: pre, wrong, post.
- `fig.*`: item figures (fig0, fig1). Stages: pre, wrong, post.
- `wrong.*`: the picked distractor: wrong.error tag, wrong.text. Stages: wrong, post.
- `key.*`: hidden answer values (key.v1); the gate drops any key ref, or literal equal to a key value, outside post. Stages: post.

## Components (`?` = optional)
### L0: primitives (escape hatch): build anything when no learning component fits
- `View(children: Component[]≤6)`: The root: its children are painted in order, each into a slot reserved when the root arrives
- `Head(title: string≤60, sub?: string≤140)`: Title and one-line subtitle of a view
- `Text(text: string≤400)`: A paragraph; **bold** is the only emphasis
### L1: learning components: subject-blind, know data shapes only
- `Doodle(kind: "duck" | "heart" | "star" | "spark", text?: string≤80)`: A small drawing when nothing else fits (visual first)
- `Steps(fig?: Scene, steps: Step[]≤8, front?: string≤32, head?: string≤24[]≤5)`: A stepper: one figure, the steps, an optional frontier row and status table; Back/Next below
- `Step(cap: string≤140, nodes?: string≤200, edges?: string≤300, tags?: string≤200, labels?: string≤40[]≤12, front?: string≤8[]≤8, rows?: string≤40[]≤5[]≤12, ops?: string≤40[]≤4, ask?: Ask)`: One step: caption, node marks "A:cur B:front", edge marks "A-B:tree", tags "A:0", edge labels ["A-B:new"], frontier, table rows
- `Scene(objs: (Shape | Link | Axes | MathRows | Code | Trace | Cells | Bars)[]≤12, qs?: Q[]≤10, rels?: string≤80[]≤12, alt?: string≤160)`: A scene in world units (y up): objects, quantities, relations; only as Steps.fig. The renderer solves it and owns every pixel and label spot (views/scene-contract.md)
- `Shape(id: string≤16, kind: "rect" | "circle" | "triangle" | "polygon" | "line" | "point", geom: string≤80, at?: string≤40, label?: string≤40, art?: "ball" | "block" | "cart" | "pulley" | "battery" | "resistor" | "bulb" | "capacitor" | "magnet" | "lens" | "mirror" | "piston" | "thermometer" | "flame" | "snowflake", role?: "body" | "guide" | "ground" | "region" | "yours" | "right")`: A shape: geom "w=10 h=0.4 segments=10", at a point "0,3" or an anchor "rod.right"; label may hold {qid} tokens
- `Link(id: string≤16, kind: "arrow" | "vector" | "spring" | "string" | "dimension" | "angle", from: string≤40, to: string≤40, label?: string≤40, q?: string≤16, geom?: string≤40)`: A connector between two points or anchors; a vector's to may be relative "+0,-1.5"; q = a Q id
- `Axes(id: string≤16, x: string≤40, y: string≤40, items: string≤80[]≤8)`: A plot frame: x / y "min,max label", items "f curve x^2/2+1", "R riemann f 0 4 n left", "m marker y 60 your guess"
- `MathRows(id: string≤16, rows: string≤60[]≤4)`: Math, one step per row, aligned on the first =; {qid} tokens
- `Code(id: string≤16, lang: "python" | "js", lines: string≤60[]≤12)`: Source lines; the highlight follows a Trace or set hl
- `Trace(id: string≤16, code: string≤16, vars: string≤60, ticks?: string≤80[]≤24)`: The engine runs a Code and shows vars per tick; never write ticks (the server fills them)
- `Cells(id: string≤16, kind: "array" | "stack" | "grid", items: string≤24[]≤12, ptrs?: string≤60)`: An array, stack or grid of cells; ptrs "i:0 j:4"
- `Bars(id: string≤16, items: string≤40[]≤6, total?: string≤40, conserve?: boolean)`: Bars "label: expr"; conserve = they share the total, so a drain shows
- `Q(id: string≤16, role: "given" | "derived" | "answer" | "unknown", value?: number, unit?: string≤12, expr?: string≤80, sym?: string≤16)`: A quantity: given (value), derived (expr), answer (expr, shown only after a solve), unknown (symbol)
- `Ask(q: string≤100, choices: string≤24[]≤4)`: A question with 2-4 choices on a scene step; the next step shows the answer to it

## Scene rules
- Goals, in order: the student understands, stays engaged, the figure is true.
- Write one `Steps(<Scene>, [steps])`. Declare every object once in the Scene with an id; steps only name ids.
- Never write a pixel, a colour or a size word. World units, y up, degrees counter-clockwise. The site places every label.
- Numbers you write: givens from the problem, small counts, or a Q expr. Never the answer: give it a Q with role answer and an expr (no value); the site shows its symbol until the student solves it.
- A middle value is a derived Q with an expr; write `{qid}` in a caption, label or row to show it.
- Shape geom: rect `w= h=` [`radius= segments= rotate=`]; circle `r=`; triangle `base= height=` [`apex=`]; polygon `pts=x,y;x,y;x,y`; line `from= to=`; point `""`.
- Anchors: `rod.right`, `rod.top@0.3` (along an edge), `ceil@0.2` (along a line or Link), `ramp.hyp@0.5`; a bare id is its center. Anchors follow the object every step.
- Link kinds: arrow, vector (`to` may be `+dx,dy`), spring `coils=`, string, dimension `offset=`, angle `at= r=`. `q` names the Q that sets a vector's length.
- Axes items: `f curve <expr in x>`, `p line x,y;x,y`, `A area f a b`, `R riemann f a b n left|right|mid|trap`, `t tangent f x0`, `d pointon f x`, `m marker x|y v label`.
- Relations (rels): `attach sp.end ball.left`, `on ball ramp.hyp 0.3`, `pivot rod rod.right`, `align a b bottom`, `distribute a b c x`, `stack cu al x`, `set al.w 2*cu.w`, `scale Fg Fn`. No cycles.
- Expressions: numbers, Q ids, `id.prop` (w h r base height apex radius segments rotate x y len), `+ - * / ^ ( )`, sqrt sin cos tan abs min max rad pi. No 1e3, no 2x.
- A scene step: `Step("caption", null, null, null, null, null, null, [ops], Ask("q", [choices]))`; the six nulls skip the graph args; Ask is optional.
- Ops (at most 4, 40 chars each): `add a b`, `set rod rotate -6`, `glow a b` (this step only), `hide a`, `camera fit a b` or `camera all`, `param n 8`.
- Step 1 sets the scene (what the student already has). After it: one change per step (one id added, set, hidden or param'd); glow and camera are free.
- 3 to 6 steps. The last step adds or moves geometry, not only math. Ask once before the last step; the next step shows the answer to it.
- Captions: at most 15 words, talk to the student (you, a command, or a question). No dashes, no !, no let's, no hype, no objects acting like people. A dense last step: split it in two.
- Trace: write the Code and `Trace(id, codeId, "i total")`; the server runs it and fills the ticks; step with `set tr tick k`.
- Bars with conserve: the items sum to the total in every step; drain one with param or set.

## Notes: mechanics
- Bodies are rect / circle / triangle Shapes; forces are vector Links from an anchor on the body; forces you compare share one `scale`.
- Torque: a point at the pivot, dimension Links for the lever arms with `{arm}` labels; tilt with `set rod rotate -6`, level with `set rod rotate 0`.
- Ramps: a triangle with apex 0; put a body on it with `on ball ramp.hyp 0.3`; energy as Bars with conserve.
- Strings and springs end on anchors, so they follow a moving body.
- Heat or flow through joined rods: `stack cu al x`, `set al.w 2*cu.w`, the profile as an Axes line, the student's guess as a marker.

## Notes: calc
- One Axes per scene; short curve ids (f, g); ranges from the givens.
- Riemann: `R riemann f a b n left` with n a given Q; double it with `param n 8`; the exact area is the answer Q.
- Tangent or secant: `t tangent f x0`, move it with `set t x 1.5`.
- The student's guess: `m marker y v your guess` (their number is a given).

## Notes: cs_trace
- Code lines exactly as the problem has them; one Trace bound to the Code; `set tr tick k` moves one tick per step.
- Cells for the list being walked; move a pointer with `set ar ptr.i 3`.
- Never write a loop value yourself: the trace computes it, and the final value stays hidden until the solve.

## Example
```
root = View([st])
st = Steps(sc, [p1, p2, p3, p4, p5, p6])
sc = Scene([ceil, rod, s1t, s2t, Wv, pv, dT, dW, eq], [T1, L, armT1, armW, W], ["pivot rod rod.right"], "A rod hung from two strings, with its weight at the middle.")
ceil = Shape("ceil", "line", "from=0,6 to=10,6", null, null, null, "ground")
rod = Shape("rod", "rect", "w=L h=0.4 segments=10", "0,3")
s1t = Link("s1t", "string", "ceil@0.2", "rod.top@0.2", "{T1} N")
s2t = Link("s2t", "string", "ceil@1", "rod.top@1", "T2")
Wv = Link("Wv", "vector", "rod.bottom@0.5", "+0,-1.5", "W")
pv = Shape("pv", "point", "", "rod.right", "pivot")
dT = Link("dT", "dimension", "rod.top@0.2", "rod.top@1", "{armT1} segments", null, "offset=1")
dW = Link("dW", "dimension", "rod.bottom@0.5", "rod.bottom@1", "{armW} segments", null, "offset=-1")
eq = MathRows("eq", ["{T1} × {armT1} = W × {armW}"])
T1 = Q("T1", "given", 100, "N")
L = Q("L", "given", 10, "seg")
armT1 = Q("armT1", "derived", null, "seg", "L-2")
armW = Q("armW", "derived", null, "seg", "L/2")
W = Q("W", "answer", null, "N", "T1*armT1/armW", "W")
p1 = Step("You took torques about the right end. Where does T1 pull?", null, null, null, null, null, null, ["add ceil rod s1t s2t Wv pv", "glow pv s1t"])
p2 = Step("Count the segments from T1 to your pivot.", null, null, null, null, null, null, ["add dT", "glow dT"])
p3 = Step("Now count from the weight to the pivot.", null, null, null, null, null, null, ["add dW", "glow dW"], Ask("Which pull has the longer arm?", ["T1", "W"]))
p4 = Step("Watch the rod tilt toward the longer arm.", null, null, null, null, null, null, ["set rod rotate -6", "glow dT"])
p5 = Step("Write both turns as one equation.", null, null, null, null, null, null, ["add eq", "glow eq"])
p6 = Step("Level the rod and solve that line for W yourself.", null, null, null, null, null, null, ["set rod rotate 0", "glow eq Wv"])
```
