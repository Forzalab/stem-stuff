# View prompt: all components (library 0.1.0, profile stem)
Generated by tools/gen_views.py from views/registry.json. Do not edit.

## Language (OpenUI Lang, profile stem)
- One statement per line: `name = Component(arg, ...)`, args in the order shown. The last tree hangs off `root = View([...])`.
- Forward refs are fine. `$name = value` declares state (Slider binds it).
- `q = Query("tool", {args}, {defaults})` asks an engine. Bind components to `q`. Never type a value an engine can compute.
- No Mutation, no Action, no navigation, no timers.

## Bank refs
- `given.*`: item givens (given.m, given.v0). Stages: pre, wrong, post.
- `fig.*`: item figures (fig0, fig1). Stages: pre, wrong, post.
- `wrong.*`: the picked distractor: wrong.error tag, wrong.text. Stages: wrong, post.
- `key.*`: hidden answer values (key.v1); the gate drops any key ref, or literal equal to a key value, outside post. Stages: post.

## Components (`?` = optional)
### L0: primitives (escape hatch): build anything when no learning component fits
- `View(children)`: root container
- `Stack(children, dir?)`: children in a row or column
- `Grid(children, cols?)`: small multiples, equal cells
- `Card(children, tag?)`: boxed group with an optional tag line
- `Text(text)`: short text; inline $math$ allowed
- `Math(tex)`: display TeX; an identity it states is re-checked
- `Table(head, rows)`: header row + body rows; cells may be refs
- `Chips(items)`: row of small chips (givens, tags)
- `Image(src, alt)`: bank image by ref, with alt text
### L1: learning components: subject-blind, know data shapes only
- `Given(ref, label?)`: one given value chip, bound to a given.* ref
- `Steps(steps, mode?)`: ordered steps, one at a time (reveal) or as tabs
- `Step(title, children)`: one step of Steps
- `Compare(children, sync?)`: side by side; sync=true steps both together
- `Callout(tag, children)`: highlighted box, e.g. tag "Where it breaks"
- `Reveal(children, when?)`: hidden until tapped or until a Predict is submitted
- `Predict(question, answer, tol?)`: student types a guess; marks it right or wrong against answer
- `Slider(value, min, max, step?, label?)`: binds a $state variable
- `Choice(question, options)`: one question with 2-3 options (low-confidence intent)
- `Assume(text, alts?)`: "I read this as X" chip; tap sends a refine request
- `Axes(axes)`: concept axes, each Axis a spectrum
- `Axis(name, left, right)`: one axis of Axes
### L2: renderers of engine data: every value comes from a Query result or a bank ref
- `Graph(fig, stage?)`: draws a bank graph block (fig ref) or one stage of a trace
- `Walk(trace)`: algorithm stepper: stages, frontier, distances from a trace
- `FlowNet(flow)`: flow network with flows and the min cut
