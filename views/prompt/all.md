# View prompt: all components (library 0.2.0, profile stem)
Generated by tools/gen_views.py from views/registry.json. Do not edit.

## Language (OpenUI Lang, profile stem)
- One statement per line: `name = Component(arg, ...)`, args in the order shown. The tree hangs off `root = View([...])`.
- Forward refs are fine. `$name = value` declares state.
- `q = Query("tool", {args}, {defaults})` asks an engine (server side). Never type a value an engine can compute.
- No Mutation, no Action, no navigation, no timers.
- The site draws every look. Never describe colours or sizes. State words are marks only: cur, done, front, rec, idle, tree, seen, skip, k1, k2, k3.
- Caps: `string≤N` = at most N characters, `[]≤N` = at most N items. Over a cap the statement is dropped.
- Nothing fits? Draw a `Doodle`. Never send a view with no visual.

## Bank refs
- `given.*`: item givens (given.m, given.v0). Stages: pre, wrong, post.
- `fig.*`: item figures (fig0, fig1). Stages: pre, wrong, post.
- `wrong.*`: the picked distractor: wrong.error tag, wrong.text. Stages: wrong, post.
- `key.*`: hidden answer values (key.v1); the gate drops any key ref, or literal equal to a key value, outside post. Stages: post; as the Predict.answer reference in any stage (the server resolves it, F5).

## Components (`?` = optional)
### L0: primitives (escape hatch): build anything when no learning component fits
- `View(children: Component[]≤6)`: The root: its children are painted in order, each into a slot reserved when the root arrives
- `Head(title: string≤60, sub?: string≤140)`: Title and one-line subtitle of a view
- `Text(text: string≤400)`: A paragraph; **bold** is the only emphasis
- `Legend(items: string≤32[]≤8)`: Legend chips, each "mark label"; the sample is drawn with the figure's own class
- `Table(head: string≤24[]≤5, rows: string≤40[]≤5[]≤12)`: A small table: header cells, then rows of cells
### L1: learning components: subject-blind, know data shapes only
- `Tug(rows: string≤110[]≤6, of?: string≤24, alt?: string≤120, net?: string≤24)`: A push-pull rope: one row per factor, "label | move | up|down|same [size 1-9]"; the bar pulls right (up) or left (down); size is the bar's relative length; of = the thing pulled; net is the end knot (post only)
- `Flip(rows: string≤40[]≤3[]≤4, alt?: string≤120)`: Cards that flip from "you did" to "the fix": rows of [step, you did, the fix]; tap a card to flip it back
- `Callout(tag: string≤24, text: string≤400)`: A section with a rule and a short tag ("Where it breaks"), never a box
- `Steps(fig?: Graph | Geometry | Doodle, steps: Step[]≤8, front?: string≤32, head?: string≤24[]≤5)`: A stepper: ONE anchor figure (Graph, Geometry or Doodle) drawn once for every step, the steps, an optional frontier row and status table; a segmented progress bar, Back/Next and Show all (every step formula) below. A Geometry fig: each Step lights its own parts (lit), the rest dims, nothing is removed
- `Step(cap: string≤140, nodes?: string≤200, edges?: string≤300, tags?: string≤200, labels?: string≤40[]≤12, front?: string≤8[]≤8, rows?: string≤40[]≤5[]≤12, tex?: string≤120, lit?: string≤120)`: One step: caption (one or two short sentences; with a Geometry fig the six Graph args are null: Step("...", null, null, null, null, null, null, "W = F s", "F s")), tex (one formula, TeX, no $), lit (a Geometry fig's parts this step lights, space separated: a point name "A", a segment "A-B", or a label as written "F" / "\theta"; every symbol in tex is a lit label; empty = all lit), node marks "A:cur B:front", edge marks "A-B:tree", tags "A:0", edge labels ["A-B:new"], frontier, table rows
- `Hints(hints: string≤200[]≤3)`: A hint ladder: one hint at a time
- `Predict(tag?: string≤24, q: string≤140, choices: string≤24[]≤5, struck?: string≤24[]≤4, tries?: number, answer: key.<id>)`: Pick an answer; the pick is posted with the answer ref to the server, the page never resolves or draws it
- `Reveal(lock: string≤80, body?: Component[]≤4)`: A visible locked row; its body arrives as a second program when the stage changes
- `Answer(value: string≤40, text?: string≤140)`: The boxed answer and one sentence
- `Doodle(kind: "duck" | "heart" | "star" | "spark", text?: string≤80)`: A small drawing when nothing else fits (visual first)
- `Geometry(pts: string≤240, marks: string≤80[]≤12, alt?: string≤160)`: A to-scale geometry figure: named points "A 0,0; B 3,0; C 3,4" (y up), marks seg(A,B) circle(O,2) right(B,A,C) dim(A,B,3 m) angle(A,B,C,$\theta$) arrow(A,C,$F$) label(C,top); at most 12 points, 12 marks, 6 labels; a number in a label is a given, never the answer; a mark may end with layer=1|2|3 (1 = what the question asks, the default; 2 = given; 3 = implied or context). Never put layer 2 or 3 on tone=bad (red stays layer 1). and tone=<ink|muted|c1|c2|c3|ok|bad|mark|sky|amber|orange|violet|pink|cyan> (figure palette hues only; an arrow with no tone gets its own hue automatically, keyed by its label, so leave tone off unless a force must be a given color; ok / bad mean right / wrong, use them only for that), e.g. arrow(A,C,$F$,tone=c1,layer=2)
### L2: renderers of engine data: every value comes from an engine result
- `Graph(nodes: string≤600, edges: string≤600, cols?: string≤200, marks?: string≤400, layer?: string≤120, tone?: string≤120)`: A graph: nodes "A 48 100, B 160 48", edges "A>B, A-C" (> directed), column labels "48 depth 0", marks "A:done u0:k1"; figure-only emphasis props layer "A:2 B-C:3" (1 = what the question asks, the default; 2 = given; 3 = implied or context). Never put layer 2 or 3 on tone=bad (red stays layer 1). and tone "A:c2 B-C:bad" (a figure palette hue: ink muted c1 c2 c3 ok bad mark)
