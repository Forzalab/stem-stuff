# View prompt: all components (library 0.2.0, profile stem)
Generated by tools/gen_views.py from views/registry.json. Do not edit.

## Language (OpenUI Lang, profile stem)
- One statement per line: `name = Component(arg, ...)`, args in the order shown. The tree hangs off `root = View([...])`.
- Forward refs are fine. `$name = value` declares state.
- `q = Query("tool", {args}, {defaults})` asks an engine (server side). Never type a value an engine can compute.
- No Mutation, no Action, no navigation, no timers.
- The site draws every look. Never describe colours or sizes. State words are marks only: cur, done, front, rec, idle, tree, seen, skip, k1, k2, k3.
- Caps: `string≤N` = at most N characters, `[]≤N` = at most N items. Over a cap the statement is dropped.
- Nothing fits? Draw a `Doodle`. Never send a view with no visual.

## Bank refs
- `given.*`: item givens (given.m, given.v0). Stages: pre, wrong, post.
- `fig.*`: item figures (fig0, fig1). Stages: pre, wrong, post.
- `wrong.*`: the picked distractor: wrong.error tag, wrong.text. Stages: wrong, post.
- `key.*`: hidden answer values (key.v1); the gate drops any key ref, or literal equal to a key value, outside post. Stages: post; as the Predict.answer reference in any stage (the server resolves it, F5).

## Components (`?` = optional)
### L0: primitives (escape hatch): build anything when no learning component fits
- `View(children: Component[]≤6)`: The root: its children are painted in order, each into a slot reserved when the root arrives
- `Head(title: string≤60, sub?: string≤140)`: Title and one-line subtitle of a view
- `Text(text: string≤400)`: A paragraph; **bold** is the only emphasis
- `Legend(items: string≤32[]≤8)`: Legend chips, each "mark label"; the sample is drawn with the figure's own class
- `Table(head: string≤24[]≤5, rows: string≤40[]≤5[]≤12)`: A small table: header cells, then rows of cells
### L1: learning components: subject-blind, know data shapes only
- `Callout(tag: string≤24, text: string≤400)`: A section with a rule and a short tag ("Where it breaks"), never a box
- `Steps(fig?: Graph | Scene, steps: Step[]≤8, front?: string≤32, head?: string≤24[]≤5)`: A stepper: one figure, the steps, an optional frontier row and status table; Back/Next below
- `Step(cap: string≤140, nodes?: string≤200, edges?: string≤300, tags?: string≤200, labels?: string≤40[]≤12, front?: string≤8[]≤8, rows?: string≤40[]≤5[]≤12, ops?: string≤40[]≤4, ask?: Ask)`: One step: caption, node marks "A:cur B:front", edge marks "A-B:tree", tags "A:0", edge labels ["A-B:new"], frontier, table rows
- `Hints(hints: string≤200[]≤3)`: A hint ladder: one hint at a time
- `Predict(tag?: string≤24, q: string≤140, choices: string≤24[]≤5, struck?: string≤24[]≤4, tries?: number, answer: key.<id>)`: Pick an answer; the pick is posted with the answer ref to the server, the page never resolves or draws it
- `Reveal(lock: string≤80, body?: Component[]≤4)`: A visible locked row; its body arrives as a second program when the stage changes
- `Answer(value: string≤40, text?: string≤140)`: The boxed answer and one sentence
- `Doodle(kind: "duck" | "heart" | "star" | "spark", text?: string≤80)`: A small drawing when nothing else fits (visual first)
- `Geometry(pts: string≤240, marks: string≤80[]≤12, alt?: string≤160)`: A to-scale geometry figure: named points "A 0,0; B 3,0; C 3,4" (y up), marks seg(A,B) circle(O,2) right(B,A,C) dim(A,B,3 m) angle(A,B,C,$\theta$) arrow(A,C,$F$) label(C,top); at most 12 points, 12 marks, 6 labels; a number in a label is a given, never the answer
- `Scene(objs: (Shape | Link | Axes | MathRows | Code | Trace | Cells | Bars)[]≤12, qs?: Q[]≤10, rels?: string≤80[]≤12, alt?: string≤160)`: A scene in world units (y up): objects, quantities, relations; only as Steps.fig. The renderer solves it and owns every pixel and label spot (views/scene-contract.md)
- `Shape(id: string≤16, kind: "rect" | "circle" | "triangle" | "polygon" | "line" | "point", geom: string≤80, at?: string≤40, label?: string≤40, art?: "ball" | "block" | "cart" | "pulley" | "battery" | "resistor" | "bulb" | "capacitor" | "magnet" | "lens" | "mirror" | "piston" | "thermometer" | "flame" | "snowflake", role?: "body" | "guide" | "ground" | "region" | "yours" | "right")`: A shape: geom "w=10 h=0.4 segments=10", at a point "0,3" or an anchor "rod.right"; label may hold {qid} tokens
- `Link(id: string≤16, kind: "arrow" | "vector" | "spring" | "string" | "dimension" | "angle", from: string≤40, to: string≤40, label?: string≤40, q?: string≤16, geom?: string≤40)`: A connector between two points or anchors; a vector's to may be relative "+0,-1.5"; q = a Q id
- `Axes(id: string≤16, x: string≤40, y: string≤40, items: string≤80[]≤8)`: A plot frame: x / y "min,max label", items "f curve x^2/2+1", "R riemann f 0 4 n left", "m marker y 60 your guess"
- `MathRows(id: string≤16, rows: string≤60[]≤4)`: Math, one step per row, aligned on the first =; {qid} tokens
- `Code(id: string≤16, lang: "python" | "js", lines: string≤60[]≤12)`: Source lines; the highlight follows a Trace or set hl
- `Trace(id: string≤16, code: string≤16, vars: string≤60, ticks?: string≤80[]≤24)`: The engine runs a Code and shows vars per tick; never write ticks (the server fills them)
- `Cells(id: string≤16, kind: "array" | "stack" | "grid", items: string≤24[]≤12, ptrs?: string≤60)`: An array, stack or grid of cells; ptrs "i:0 j:4"
- `Bars(id: string≤16, items: string≤40[]≤6, total?: string≤40, conserve?: boolean)`: Bars "label: expr"; conserve = they share the total, so a drain shows
- `Q(id: string≤16, role: "given" | "derived" | "answer" | "unknown", value?: number, unit?: string≤12, expr?: string≤80, sym?: string≤16)`: A quantity: given (value), derived (expr), answer (expr, shown only after a solve), unknown (symbol)
- `Ask(q: string≤100, choices: string≤24[]≤4)`: A question with 2-4 choices on a scene step; the next step shows the answer to it
### L2: renderers of engine data: every value comes from an engine result
- `Graph(nodes: string≤600, edges: string≤600, cols?: string≤200, marks?: string≤400)`: A graph: nodes "A 48 100, B 160 48", edges "A>B, A-C" (> directed), column labels "48 depth 0", marks "A:done u0:k1"
